Set up your device

Tell the device which WiFi to use when you park at home. This takes about a minute, once.

This network looks like it uses WPA3 only. The device can’t scramble the password for WPA3 networks — it would have to store the password itself. If you’d rather not, pick a different network or contact the researcher.

Your password is not sent to us. It’s scrambled on this phone into a code that only works for this one network, and only that code leaves your phone. The researchers never see your password, and it is never stored on the device or written down anywhere.
